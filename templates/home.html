Welcome to ArtLens

Where Deep Learning Meets Artistic Expression

About the Project

ArtLens is a cutting-edge web platform that uses deep learning to classify artwork styles. Powered by a Convolutional Neural Network, it identifies famous art styles such as Cubism, Impressionism, and Abstract, offering both educational insight and artistic exploration.

🎯 Purpose

Bridge the gap between AI and Art by automating the style classification process using CNN models.

🛠 Tech Stack

Built using Python, TensorFlow with a clean frontend for intuitive use.

📚 Dataset

Trained on a large curated dataset of classical and modern paintings from various eras.
